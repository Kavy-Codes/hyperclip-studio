# Reaction Short

Use when the value is a person reacting to a source moment. The source moment and
the reaction must both be legible.

## Build

1. Identify the **source moment** and the **reaction peak**. They are different
   timestamps; do not assume they align.
2. Confirm rights for the reaction footage and the source clip separately.
3. Create a portrait project:
   `STUDIO/scripts/new-clip.sh <slug> --channel Clipworthy --duration 20`
4. Add `ambient-bg` at track 0.
5. Put the reaction in a bottom or full-screen wrapper; put the source clip in a
   framed panel above or beside it. Keep faces visible.
6. Add `hook` for the first 2–3s: name the tension, not the whole payoff.
7. Add `caption` for the exact reaction line.
8. Add `payoff` when the reaction and the source moment resolve together.
9. Add `lower-third` only if the person's identity matters.
10. `check` → draft → frame review → final.

## Framing

- Do not crop the source so tightly that the action is unreadable.
- Keep the reaction face and the source action in the same glance.
- Use a seam/feather between stacked panels; avoid a razor-sharp hard edge.
- Muted viewers should still understand the tension.

## Avoid

- Reaction audio that is buried under the source audio.
- A source clip used only as decoration.
- Implying endorsement or a real reaction that did not happen.
- Publishing without a rights answer for both layers.
